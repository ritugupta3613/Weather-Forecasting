# Weather Forecasting

A simple web-based Weather Forecasting application that provides weather information for a searched location using a weather API.

## 🚀 Features

- 🌤️ Search weather by city
- 🌡️ Display temperature and weather conditions
- 💧 Display humidity
- 💨 Display wind information
- 📍 Fetch weather data using a weather API
- 📱 Simple and responsive interface

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Weather API

## ▶️ Run Locally

Open the project in your browser or use a local development server.

```text
index.html
```
